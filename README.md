# Numerical experiments for the Bethe--Hessian

This repository contains the MATLAB code for the numerical
experiments accompanying [Negative Spectrum of the Bethe--Hessian at the Percolation Threshold].

## Reproducing the experiments

The script `bethe_hessian_neg_test.m` finds the distribution of the second smallest eigenvalue of the Bethe Hessian on an Erdős-Rényi graph of expected degree d on N vertices. I ran this on MATLAB R2023a. The figure gives the result of my test, where a positive fraction of the time, the second eigenvalue is negative.
